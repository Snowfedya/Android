# Setup Lab Environment

## Task: /project:setup-lab <lab_number>

**Steps**:
1. Create new branch `lab-<number>` from previous lab
2. Copy base code from previous lab if exists
3. Add lab-specific dependencies to build.gradle
4. Update AndroidManifest with required permissions
5. Create README.md with lab requirements
6. Initialize git commit: "chore: setup lab-<number> environment"

**Arguments**: `$ARGUMENTS` = lab number (1-7)
